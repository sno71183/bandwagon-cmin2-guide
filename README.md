## 一、先把概念搞清楚：CMI和CMIN2不一样

**移动优化VPS**，指的是回程路由针对中国移动方向做了优化的VPS，核心是走AS58807（CMIN2）或AS58453（CMI）这两条移动线路，而不是绕道普通国际出口。

两个容易混淆的名词：

**CMI（China Mobile International，AS58453）**：移动的普通国际线路，质量尚可，大部分支持"移动优化"的VPS走的就是这条。

**CMIN2（China Mobile International Network 2，AS58807）**：移动2022-2023年新推出的精品专线，相当于移动版的CN2 GIA，独立出海通道，QoS优先级更高，晚高峰表现比CMI稳定得多。

两条线路的区别，关键看路由里的ASN号：
- 看到 `AS58453` → CMI，普通线路
- 看到 `AS58807` → CMIN2，精品线路

搬瓦工的DC6和DC9机房在2024年底正式接入CMIN2，官方公告原文表示移动方向的延迟和吞吐量都有"显著提升"。这对移动用户来说是个实质性利好。
